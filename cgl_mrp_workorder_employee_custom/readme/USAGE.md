Open a Manufacturing Order, go to a work order and open the "Time
Tracking" tab (visible to Manufacturing Managers).

- When a timer is started/stopped, the new line is filled in with the
  employee linked to the logged in user, if any.
- The Employee column can also be set or changed manually on any line.
- Users without a linked employee can still select one manually; the
  field is left empty by default in that case.
