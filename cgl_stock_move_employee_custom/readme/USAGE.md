The User column is available in:

- Manufacturing Orders, tab Components (right after the "From" column).
- Repair Orders, tab Parts.
- Inventory transfers and Delivery Orders, tab Operations.
- The "Inventory Moves" / "Movimentações de produtos" report opened from
  the Product Moves smart button (right after the "From" column).

Select the user (employee) who performed the stock withdrawal directly on
the line. It is optional and can be left empty or changed at any time.
